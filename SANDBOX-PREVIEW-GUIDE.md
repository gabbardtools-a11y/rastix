## ⚡ Краткая версия (3 шага)

```bash
# 1. Убедись, что dev-скрипт использует порт 3000 (НЕ 3007!)
#    В package.json: "dev": "next dev -p 3000 ..."

# 2. Запусти сервер через pm2 (он не умрёт!)
cd /home/z/my-project
pm2 start "npx next dev -p 3000" --name rastix-dev

# 3. Вызови Complete — сандбокс подключится
#    Complete(project_type="web_dev", summary="3axap.su — превью (zakhar-2)")
```

## 📖 Подробная инструкция

### Шаг 1. Проверь порт в package.json

Сандбокс работает **только на порту 3000**. Если в `package.json` указан порт 3007 — превью не появится!

**Неправильно:**
```json
"dev": "next dev -p 3007 2>&1 | tee dev.log"
```

**Правильно:**
```json
"dev": "next dev -p 3000 2>&1 | tee dev.log"
```

Исправь файл `/home/z/my-project/package.json` — замени `3007` на `3000` в строке `"dev"`.

---

### Шаг 2. Убей старые процессы

Если до этого запускал `npm run dev` или `npx next dev` — убей их:

```bash
pkill -f "next dev" 2>/dev/null
sleep 1
```

---

### Шаг 3. Установи pm2 (если нет)

pm2 — менеджер процессов. Он держит сервер живым **постоянно**, даже после завершения работы чат-бота.

```bash
which pm2 2>/dev/null && echo "Уже установлен" || npm install -g pm2
```

---

### Шаг 4. Запусти сервер через pm2

```bash
cd /home/z/my-project
pm2 start "npx next dev -p 3000" --name rastix-dev
```

Подожди ~8 секунд, потом проверь:

```bash
pm2 list
curl -s -o /dev/null -w "HTTP: %{http_code}\n" http://localhost:3000/
```

Должно быть:
- **status:** `online`
- **HTTP:** `200`

---

### Шаг 5. Вызови Complete

В конце работы вызови инструмент Complete:

```
Complete(project_type="web_dev", summary="3axap.su — превью (zakhar-2)")
```

После этого справа в чате появится **Preview Panel** с превью сайта.

## 🐛 Частые проблемы и решения

### Проблема 1: Превью не появляется вообще

**Причина:** Сервер запущен на порту 3007, а сандбокс ждёт порт 3000.

**Решение:** Убей процесс, исправь порт на 3000, запусти заново:
```bash
pkill -f "next dev"
# Исправь package.json (3007 → 3000)
pm2 restart rastix-dev
```

---

### Проблема 2: Превью появляется, но пропадает после завершения

**Причина:** Сервер запущен через `nohup ... &` — процесс умирает, когда сессия завершается.

**Решение:** Запускай только через pm2:
```bash
pm2 start "npx next dev -p 3000" --name rastix-dev
```
pm2 запускает сервер как **демон** — он переживает завершение сессии.

---

### Проблема 3: pm2 пишет «process failed» или «errored»

**Причина:** Порт 3000 занят старым процессом.

**Решение:**
```bash
pm2 delete rastix-dev
pkill -f "next dev"
sleep 2
pm2 start "npx next dev -p 3000" --name rastix-dev
```

---

### Проблема 4: Ссылка preview-xxx.space-z.ai выдаёт 404

**Причина:** Ссылки формата `https://preview-xxx.space-z.ai/` не работают напрямую. Превью доступно **только** через Preview Panel в чате.

**Решение:** Не используй прямые ссылки. Превью появляется справа в чате после вызова Complete.

## 📋 Чек-лист перед запуском

- [ ] `package.json`: порт 3000 в dev-скрипте
- [ ] Старые процессы убиты (`pkill -f "next dev"`)
- [ ] pm2 установлен (`which pm2`)
- [ ] Сервер запущен через pm2 (`pm2 list` → status: online)
- [ ] HTTP 200 на localhost:3000
- [ ] Complete вызван с `project_type="web_dev"`

## 🔧 Полезные команды pm2

```bash
pm2 list                 # Список процессов и их статус
pm2 logs rastix-dev      # Логи сервера (Ctrl+C для выхода)
pm2 restart rastix-dev   # Перезапуск
pm2 stop rastix-dev      # Остановка
pm2 delete rastix-dev    # Удаление процесса
pm2 monit                # Мониторинг в реальном времени
```
